# 纸上冒险 · 纸雕车卡工坊

以 [Curio 348](https://curio.taugocauci.dev/item/348) 的实体纸卡为视觉参考，沿用「01 原片纸雕」的厚纸开窗、彩绘底稿与手工切口，制作可以填写、组合和保存角色的交互工坊。身份、属性、技能、装备和背景都成为独立纸雕组件。

参考视频展示实体纸卡的制作过程与最终成品。工坊中的拖动、编辑、规则检查和保存，是为数字车卡流程增加的操作。

## 入口

- 工坊页面：`dist/workshop.html`。
- 本地试用地址：[纸雕车卡工坊](http://127.0.0.1:4378/workshop.html)。
- 线上入口地址：[纸雕车卡工坊](https://paper-adventure-ten-studies.shenzh2012.chatgpt.site/workshop.html)。

用静态文件服务器打开 `dist/` 即可运行，无需安装依赖或执行构建。

## 先做一张角色卡

从空白角色开始，或在「我的角色」中选择骑士示例。六步流程可以按顺序填写，也可以点选桌面组件回到对应步骤。

| 步骤 | 可以填写和调整的内容 |
|---|---|
| 1. 身份 | 姓名、年龄、等级、职业及外貌。完成角色前，需要保留身份组件并填写姓名。 |
| 2. 属性 | 自定义名称、缩写和数值；可增加或移除条目，按需开启组件规则。 |
| 3. 技能 | 自定义技能名称和数值；可增加或移除条目，按需开启组件规则。 |
| 4. 装备 | 名称、数量、单件重量、说明及是否装配；自动汇总件数和重量。 |
| 5. 背景 | 为故事片段命名并填写内容；可添加、移除来历、牵挂、秘密等片段。 |
| 6. 检查装订 | 汇总填写问题与已启用的规则错误；点选问题返回调整，通过后完成并保存。 |

可以根据角色需要删去属性、技能、装备或背景组件。检查装订会检查当前保留的组件，不要求每类都装入；身份与姓名仍是完成角色的必要信息。

## 直接在纸上填写

双击纸面上带编辑标记的文字或数值，或先选中纸片再点击铅笔图标，即可原位填写。输入框直接出现在纸上，连续输入时保留焦点；点击「完成填写」退出。填写阶段使用纸面编辑，最后的「检查装订」会在桌面下方展示汇总。

在同一张纸片上展开「条目与规则」，可增删条目、修改详细内容、设置可选规则，并在「组件设置 · 标题与宽度」中调整标题与半宽 / 整宽。已启用规则的问题会显示在纸面上，原数值会保留，方便继续修正。

## 自由摆放与快捷键

从组件匣添加五类纸片，同一类可以放入多张。直接抓住纸面拖动，允许错位和叠压；拿起时阴影加深并轻微倾斜，松开后有落下过渡。点击纸片选中，按 Escape 或点击桌面空白处取消选择。

| 操作 | 快捷键 |
|---|---|
| 逆时针 / 顺时针旋转 3° | `A` / `D`，旋转范围为 −15° 至 +15°。 |
| 复制为独立纸片 | `⌘D` / `Ctrl+D`。 |
| 拆下已装入主卡的纸片；移除散片 | `Delete` / `Backspace`。 |
| 撤销填写、拆装、复制或摆放 | `⌘Z` / `Ctrl+Z`。 |

鼠标按住纸片时也可以按 `A` / `D`，纸片会围绕抓取点旋转；松手保留角度，`Esc` 取消本次抓取，撤销一次可同时恢复移动与旋转。对已装入主卡的组件单独旋转时，会先将它拆为散片。输入框中这些快捷键不作用于纸片。

复制得到的纸片保持独立。「整理桌面」会重新平铺散片，仍可撤销。位置、角度、叠放层次和宽度随草稿保存，并保留在 JSON 中；打印时自动排齐，桌面摆放保持原样。

## 拼成整卡与拆装

点击「拼成整卡」，将纸片装入同一张主卡：身份与人物窗在左，属性、HP / MP 与雷达在右，装备和 Q 版小像在下方；技能和背景作为附页继续展开。整卡与散片共用同一份角色数据，每个组件仍保留数据绑定和编辑能力，主卡文字与数值也能直接填写。

选中已装入主卡的组件后按 `Delete` / `Backspace`，会把它拆到桌面，保留组件及全部内容；再次对散片执行该快捷键才会移除组件。将散片拖回主卡底纸可重新装入，点击主卡的空槽位也可装回对应组件。「拆回散片」一次拆出全部组件。

组件绑定、装入状态及散片姿态会随草稿和 JSON 一起保存。「预览整卡」可查看当前组合，打印时自动排齐。

## 默认自由填写，可选规则校验

属性与技能默认接受任意有限数值，包括负数和小数，不套用某个游戏的属性范围、百分比或检定阈值。完整数字会保留，纸孔仅是辅助观看的相对刻度。

在属性或技能纸片的「条目与规则」中展开「规则校验」，勾选「启用本组件规则校验」后，可分别设置：

- **总额**：本组件所有条目的数值合计必须等于该总额；留空表示不限总额。
- **最小值、最大值**：每一项数值需要满足的范围；任一项留空，就不限制该侧边界。
- **只允许整数**：开启后，带小数的条目会报告错误。

纸面实时显示检查结果；「检查装订」会汇总问题，并在错误未解决时阻止完成。填写值不会被自动截断或替换，超出范围、超出总额或不符合整数要求的原数值仍留在卡片里，方便自行修正。关闭校验会保留已填规则，之后可以再次开启。

这是**自定义模板规则校验**，尚未内置任何一种 TRPG 的完整规则。不会根据职业自动分配点数，也不自动计算某个游戏的派生属性、战斗结果或检定难度。年龄、等级、装备数量和重量保留各自的基础数据检查。

## 草稿、角色库与备份

填写和布局调整自动保存到当前浏览器本地，草稿与完成的角色都收在「我的角色」中。

- **撤销**：恢复本次编辑中的先前内容或布局，也可用 `⌘Z` / `Ctrl+Z`。
- **多角色库**：新建角色、重新打开草稿，或继续调整已装订的角色。
- **独立克隆**：复制角色会创建新的角色与组件标识；原卡保持独立。
- **JSON 导出**：保存角色内容、组件绑定与装入状态、散片位置、角度、叠放层次、宽度和规则配置，可作为备份。
- **JSON 导入**：从「我的角色」选择文件，单个文件最大 32 MB；导入为独立角色，保留库中已有角色。遇到格式问题会给出说明。
- **打印 / PDF**：完成面板中的「打印 / 存为 PDF」打开浏览器打印界面，纸片会自动排齐，可打印整卡或选择保存为 PDF；桌面摆放保持原样。

浏览器之间不会自动同步；跨设备使用时，可导出 JSON，再在另一台设备导入。

## 文件结构

- `dist/workshop.html`：车卡工坊入口、六步导航、桌面与角色库等面板。
- `dist/workshop/workshop.js`：流程、纸面编辑、自由移动与旋转、整卡拆装、撤销、角色库、导入导出和打印操作。
- `dist/workshop/workshop-model.js`：角色数据、组件绑定与装入状态、独立克隆、导入规范化与校验。
- `dist/workshop/workshop-forms.js`：纸片上的五类详细表单与可选规则配置。
- `dist/workshop/workshop-cards.js` / `workshop-cards.css`：纸雕组件内容与外观。
- `dist/workshop/workshop.css`：工坊布局、操作区与打印样式。
- `dist/index.html`、`paper.js`、`paper.css`：原十个视觉变体参考。
- `dist/paper-touch.js` / `paper-touch.css`：原参考页的轻微光位与按压反馈。
- `dist/assets/`：人物、装备、纸纤维和桌面素材。
