# 纸上冒险 · 纸雕车卡工坊

以 [Curio 348](https://curio.taugocauci.dev/item/348) 的实体纸卡为视觉参考，沿用「01 原片纸雕」的厚纸开窗、彩绘底稿与手工切口，制作可以填写、组合和保存角色的交互工坊。立绘、身份文字、HP、MP、每条属性、雷达、每项技能、每件装备和每段背景都可成为单独的纸片，分别拖动、缩放和旋转。

参考视频展示实体纸卡的制作过程与最终成品。工坊中的拖动、编辑、规则检查和保存，是为数字车卡流程增加的操作。

## 入口

- 工坊页面：`dist/workshop.html`。
- 本地试用地址：[纸雕车卡工坊](http://127.0.0.1:4378/workshop.html)。
- 线上旧版地址：[纸雕车卡工坊](https://paper-adventure-ten-studies.shenzh2012.chatgpt.site/workshop.html)。本轮单张纸片与组合功能仅在本地提供，尚未发布到线上。
- 原十个视觉变体：`dist/index.html`，可用 `?v=1` 至 `?v=10` 选择。

用静态文件服务器打开 `dist/` 即可运行，无需安装依赖或执行构建。

## 先做一张角色卡

从空白角色开始，或在「我的角色」中选择骑士示例。六步流程可以按顺序填写，也可以点选桌面组件回到对应步骤。

| 步骤 | 可以填写和调整的内容 |
|---|---|
| 1. 身份 | 姓名、年龄、等级、职业及外貌。完成角色前，需要保留身份组件并填写姓名。 |
| 2. 属性 | 自定义名称、缩写和数值；可增加或移除条目，按需开启组件规则。 |
| 3. 技能 | 自定义技能名称和数值；可增加或移除条目，按需开启组件规则。 |
| 4. 装备 | 名称、数量、单件重量、说明及是否装配；自动汇总件数和重量。 |
| 5. 背景 | 为故事片段命名并填写内容；可添加、移除来历、牵挂、秘密等片段。 |
| 6. 检查装订 | 汇总填写问题与已启用的规则错误；点选问题返回调整，通过后完成并保存。 |

纸面上展示哪些内容可以自由选择。收回纸片会保留角色数据及其校验；需要删除某项实际数据时，在「条目与规则」中移除对应条目。身份与姓名仍是完成角色的必要信息。

## 直接在纸上填写

双击纸面上带编辑标记的文字或数值，或先选中纸片再点击铅笔图标，即可原位填写。输入框直接出现在纸上，连续输入时保留焦点；点击「完成填写」退出。填写阶段使用纸面编辑，最后的「检查装订」会在桌面下方展示汇总。

纸面填写会写回对应的角色数据。修改属性时，雷达图同步变化；显示同一数据的其他纸片也会更新。在纸片上展开「条目与规则」，可增删实际条目、修改详细内容和设置规则。已启用规则的问题会显示在纸面上，原数值会保留，方便继续修正。

## 自由摆放与快捷键

组件匣可添加单张立绘、身份文字、HP、MP、属性条、雷达、技能条、装备窗或背景便笺。每张都能单独抓起，拖到任意落点，允许错位和叠压；拿起时阴影加深并轻微倾斜，松开后有落下过渡。选中纸片后，拖动四角可以等比例调整大小，故事笺会随宽度重新排版。按 Escape 或点击桌面空白处取消选择。

| 操作 | 快捷键 |
|---|---|
| 逆时针 / 顺时针旋转 3° | `A` / `D`，旋转范围为 −15° 至 +15°。 |
| 多选或移出选择 | 按住 `Shift` 点击纸片；已组合的纸片按整组选入或移出。 |
| 组合 / 解组 | `G` / `Shift+G`，也可使用底部选择条。 |
| 复制选中的纸片或整组 | `⌘D` / `Ctrl+D`，数据关系见下文。 |
| 从底卡拆出；将散片或整组收回组件匣 | `Delete` / `Backspace`。 |
| 撤销填写、拆装、复制或摆放 | `⌘Z` / `Ctrl+Z`。 |

鼠标按住纸片时也可以按 `A` / `D`，纸片会围绕抓取点旋转；松手保留角度，`Esc` 取消本次抓取，撤销一次可同时恢复移动与旋转。已装入底卡的组件旋转后仍留在底卡上。输入框中这些快捷键不作用于纸片。

复制纸片时，数据关系取决于内容：

- **属性、技能、装备、背景条目**：创建新的独立条目与纸片，后续修改互不影响。
- **立绘、身份文字、HP、MP、雷达**：添加同一角色数据的另一张展示纸片，数值保持同步，各自的摆放独立。

「整理桌面」会重新平铺散片，组合按一个整体摆放，仍可撤销。每张纸片的位置、大小、角度和叠放层次会随草稿保存，并保留在 JSON 的 `parts` 布局中。

## 揭开镂空纸面

点击顶部「揭开纸面」，可以看到立绘、HP、MP、属性孔、雷达、装备窗和技能条的两层结构：下层保留彩绘与数值对应的色块，上层是真正带有透明窗口的纸面。面纸揭起时，镂空处会露出下方的底纸或桌面，纸边与投影随之分开。

「盖回纸面」或 `Esc` 将两层重新对齐。揭开时仍可抓住底纸移动组件或整组，纸片的位置、大小和组合关系不因揭开而改变。点击铅笔或双击底纸会先合回面纸，再原位填写；打印也使用合拢状态。身份文字与背景便笺保留普通纸面。

揭开仅是查看结构的临时状态，不写入角色数据或撤销记录。每个镂空组件的面纸和底纸共同作为一张可摆放组件，现有 `G` 组合可继续把多个组件连成一组。

## 把纸片组合起来

按住 Shift 点选多张纸片，再按 `G` 或点击底部选择条的「组合」。已有组合按整组选入、移出选择；`Shift+G` 或「解组」恢复单张摆放。

组合后，拖动任意成员会移动全部纸片；拖外层选框的四角可缩放整组，`A` / `D` 可旋转整组，抓取过程中同样可用。`⌘D` / `Ctrl+D` 复制整组，并延续上面的条目复制与共享数据规则，新组和原组的布局互不影响。

对已装入底卡的组合按 `Delete` / `Backspace`，先把整组拆到桌面；再次执行会将整组收回组件匣，从组件匣恢复时也整组放回。`Esc` 取消当前手势或选择，一次撤销可恢复整次组合操作。

「铺开底卡」「全部拆出」和「参考排版」也保留组合内部的位置、尺寸与角度，整体移动它们。

组合仅关联纸片的布局，不合并数值或规则。每张纸片的铅笔仍能编辑它自身对应的数据。分组关系以 `groupId` 随草稿和 JSON 保存；导入、复制角色或复制整组会保留各自关系，避免原件与副本串组。

## 自由拼装底卡

点击「铺开底卡」得到一张空白底纸，再把纸片逐张拖到想放的位置，按自己的构图调整大小、角度和叠压关系。「参考排版」提供一个可选起点，之后每张纸片仍能自由移动和缩放。底卡与散片共用同一份角色数据，每个组件保留独立的编辑能力。

选中已装入底卡的纸片后按 `Delete` / `Backspace`，先拆到桌面；对散片再次执行，则收回组件匣，角色数值仍保留。组件匣的「收回的纸片」可将它恢复到桌面。把散片拖回底纸任意位置即可重新装入。「全部拆出」一次将纸片放回桌面，留下一张空白底卡。实际删除角色条目需通过「条目与规则」。

装入底卡的纸片以底卡为基准记录位置、大小和角度，数据关联、装入或收回状态与叠放层次一起保存在草稿及 JSON 中。「看全底卡」仅缩小查看比例，仍可直接拖动和缩放；「原大纸面」恢复近看。「预览整卡」保留当前布局。自由底卡打印时保持当前排布，散片打印继续自动排齐。

## 默认自由填写，可选规则校验

属性与技能默认接受任意有限数值，包括负数和小数，不套用某个游戏的属性范围、百分比或检定阈值。完整数字会保留，纸孔仅是辅助观看的相对刻度。

在属性或技能纸片的「条目与规则」中展开「规则校验」，勾选「启用本组件规则校验」后，可分别设置：

- **总额**：本组件所有条目的数值合计必须等于该总额；留空表示不限总额。
- **最小值、最大值**：每一项数值需要满足的范围；任一项留空，就不限制该侧边界。
- **只允许整数**：开启后，带小数的条目会报告错误。

纸面实时显示检查结果；「检查装订」会汇总问题，并在错误未解决时阻止完成。填写值不会被自动截断或替换，超出范围、超出总额或不符合整数要求的原数值仍留在卡片里，方便自行修正。关闭校验会保留已填规则，之后可以再次开启。

这是**自定义模板规则校验**，尚未内置任何一种 TRPG 的完整规则。不会根据职业自动分配点数，也不自动计算某个游戏的派生属性、战斗结果或检定难度。年龄、等级、装备数量和重量保留各自的基础数据检查。

## 草稿、角色库与备份

填写和布局调整自动保存到当前浏览器本地，草稿与完成的角色都收在「我的角色」中。

- **撤销**：恢复本次编辑中的先前内容或布局，也可用 `⌘Z` / `Ctrl+Z`。
- **多角色库**：新建角色、重新打开草稿，或继续调整已装订的角色。
- **独立克隆**：复制角色会创建新的角色、组件和分组标识；原卡与副本各自独立，不会串组。
- **JSON 导出**：保存角色内容、`parts` 纸片布局、`groupId` 分组关系、数据关联、装入或收回状态及规则配置；每张纸片的位置、大小、角度与叠放层次均保留，底卡纸片以底卡为基准记录布局。
- **JSON 导入**：从「我的角色」选择文件，单个文件最大 32 MB；导入为独立角色，保留库中已有角色。遇到格式问题会给出说明。
- **打印 / PDF**：完成面板中的「打印 / 存为 PDF」打开浏览器打印界面。自由底卡保留当前排布，散片自动排齐；可打印或保存为 PDF，桌面布局保持原样。

旧版五组组件会自动拆细为单张纸片，保留原有角色内容与数据关联。浏览器之间不会自动同步；跨设备使用时，可导出 JSON，再在另一台设备导入。

## 文件结构

- `dist/workshop.html`：车卡工坊入口、六步导航、桌面与角色库等面板。
- `dist/workshop/workshop.js`：流程、纸面编辑、自由移动、缩放与旋转、底卡拆装、撤销、角色库、导入导出和打印操作。
- `dist/workshop/workshop-model.js`：角色数据、`parts` 布局与数据关联、独立克隆、导入规范化与校验。
- `dist/workshop/workshop-forms.js`：纸片上的五类详细表单与可选规则配置。
- `dist/workshop/workshop-parts.js` / `workshop-parts.css`：立绘、资源条、属性、雷达、技能、装备及故事等单张纸片的渲染、尺寸与拆分。
- `dist/workshop/workshop-layers.css`：镂空面纸、彩绘底纸、揭起投影与合拢动效。
- `dist/workshop/workshop-cards.js` / `workshop-cards.css`：原分组纸雕组件与兼容渲染。
- `dist/workshop/workshop.css`：工坊布局、操作区与打印样式。
- `dist/index.html`、`paper.js`、`paper.css`：原十个视觉变体参考。
- `dist/paper-touch.js` / `paper-touch.css`：原参考页的轻微光位与按压反馈。
- `dist/assets/`：人物、装备、纸纤维和桌面素材。

## 交互回归检查

检查入口为 `node tests/model-check.mjs`、`node tests/held-rotation-check.mjs`、`node tests/free-composition-check.mjs` 和 `node tests/atomic-paper-check.mjs`。单张纸片阶段的模型检查与 55 项交互回归通过，覆盖单片拖动、抓取中旋转、四角缩放、取消与撤销、两类复制、收回恢复及保存往返；80 件装备的全部位置也经过往返验证。

单张纸片阶段的本地浏览器已实际验证 HP 单独拖动、立绘与单件装备独立缩放、复制装备后独立改名、拆下与收回恢复、属性同步雷达、规则错误定位，以及 24 张纸片刷新后位置和尺寸保持一致。

组合回归脚本为 `node tests/group-composition-check.mjs`。本轮新增 29 项组合检查通过，与原有检查合计 84 项互动回归，加模型检查全部通过；覆盖多选、组合与解组、整体移动 / 缩放 / 旋转、复制、收回恢复、取消撤销、分组保存，以及整理、铺底卡、全部拆出和参考排版保持组内几何。

本地浏览器另已验证 HP 与 MP 组合后同步移动、缩放和旋转，跨类型纸片组合，整组复制收回恢复，刷新后点选任一成员选中整组，以及解组撤销、全部拆出撤销后完整恢复布局。

镂空分层检查为 `node tests/layers-check.mjs`，新增 16 项检查通过，连同既有交互合计 100 项检查及模型检查通过。覆盖七类组件的独立面纸与底纸、透明孔、复制与实时重绘后的遮罩引用、纸面填写与色条联动，以及揭开状态不修改布局。浏览器另已验证真实镂空、揭开后 HP/MP 整组拖动、撤销恢复全部 24 张纸片排版，以及填写时自动合回。
