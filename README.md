# 纸上冒险 · 十种纸雕角色卡

以 [Curio 348](https://curio.taugocauci.dev/item/348) 的实体纸卡为视觉参考，制作十个可切换的数字 Demo。共同结构是左侧人物窗、右侧状态条与属性孔、下方装备窗及独立 Q 版肖像；上层厚纸开窗，透出下层的彩绘底稿。

参考视频展示的是实体纸卡制作过程及最终成品。此 Demo 中的拖动、点按、揭层、编辑和保存，是为数字预览增加的操作，不代表视频展示了这些交互。

## 本地预览

用静态文件服务器打开 `dist/`，入口为 `dist/index.html`，无需安装依赖或执行构建。地址加上 `?v=1` 至 `?v=10` 可直接进入对应变体。

底部缩略卡、上一张/下一张按钮可切换方向；非输入状态、无弹窗时也可使用键盘左右方向键。窄屏使用横向滚动的变体栏，卡面保持同一纵横比。

## 十个变体

| 编号 | 名称 | 纸面变化 | 属性 |
|---|---|---|---|
| 01 | 原片纸雕 | 保留原片的竖卡构图、不规则人物窗、状态条、装备格与纸孔 | 六项 |
| 02 | 八属性调查卡 | 将八项属性及八轴星图嵌入同一张紧凑纸卡 | 八项 |
| 03 | 盾形人物窗 | 人物开窗改为下端收尖的盾形，纸色略带暖褐 | 六项 |
| 04 | 森林拱窗 | 圆拱人物窗、藤蔓笔迹和偏绿的旧纸色调 | 八项 |
| 05 | 星图纸筋 | 斜切角人物窗、较克制的颜色与六片星图小窗 | 六项 |
| 06 | 远行票根 | 人物窗使用剪角及侧边缺口，搭配通行证页签 | 八项 |
| 07 | 彩铅涂记 | 原形人物窗、更鲜明的彩铅色块与星图配色 | 六项 |
| 08 | 圆拱徽章 | 人物窗改为长椭圆徽章，外围保留较宽的纸面 | 六项 |
| 09 | 夜色旧卷 | 尖拱人物窗、较暗的褐色纸面及低亮度彩绘 | 八项 |
| 10 | 行囊装订页 | 左边增加装订孔与缝线，人物窗保留手切矩形轮廓 | 八项 |

十种方向共享同一角色数据，切换外观不会新建角色。六项属性为 STR、CON、DEF、SPD、INT、LUC；八项属性为 STR、CON、SIZ、DEX、APP、POW、INT、EDU，共有的属性键共享数值。

## 当前交互

- **查看纸张层次**：点击“揭开纸面”移开镂空上层，查看下方人物、装备和色块；再次点击盖回。桌面端“看细节”可放大卡面。
- **编辑卡面**：直接填写姓名；拖动 HP / MP 色条；点按属性孔设置 1–7 格并更新星图；点按装备格切换装备/收起状态。
- **等级与成长星**：点击等级在 1–20 之间循环；左侧星星可设置 1–5 颗成长星。
- **填写角色**：顶部按钮或右下小肖像打开编辑面板，可填写姓名、年龄、职业、属性、入局缘由及重要之人。
- **展开模板组件**：“技艺与特征”可编辑六项示例技能、特征和外貌，技能值旁显示向下取整的二分之一、五分之一；“背景组件”可填写信念、重要地点和宝贵之物。
- **保留与导出**：角色修改和收藏保存在当前浏览器的本地存储中；“保存卡片”导出包含当前变体编号与角色数据的 JSON。窄屏会收起收藏及导出按钮。

这是视觉与模板交互原型。属性采用简化的 **1–7 格纸孔**，HP / MP 为独立的 0–100 色条；尚未接入正式规则计算、职业点分配、掷骰流程或角色库。技能阈值仅做数值展示，选择职业不会自动套用职业规则。导出的是数据文件，不是卡面图片；当前没有导入入口或跨设备同步。

## 素材与制作方向

当前页面使用以下新生成素材，文件均位于 `dist/assets/`。下面概述生成时的视觉方向，不是原始提示词逐字记录。

| 文件 | 用途与生成方向 |
|---|---|
| `knight-cutout.png` | 主人物：红发剑盾骑士、绿色衣装与旧披巾；手绘钢笔线稿、细密排线、克制彩铅和淡水彩质感。 |
| `chibi-cutout.png` | 独立 Q 版小像：同一骑士的头身比例变化，保留红发、面甲、剑盾和配色，放入右下小窗。 |
| `gear-atlas.png` | 六格装备图集：短剑、盾牌、头盔、胸甲、腰包、靴子；不规则墨线，橙、蓝、绿淡色衬底。 |
| `paper-fiber.png` | 暖米白手工纸纤维纹理，用于底纸、镂空面板、页签及编辑面板。 |
| `desk-map.png` | 暗褐皮革桌面与边缘淡地图线迹，中央留出安静区域承托纸卡。 |

纸面开孔由 SVG 遮罩生成；人物窗、HP / MP 窗、圆孔、装备窗及星图之间的纸筋来自同一套几何结构。孔沿投影、错位墨线、纸边和底稿分别绘制，揭层时能看到它们的对应关系。页面所用图片从本地资源加载。

## 文件结构

- `dist/index.html`：预览页面、工具按钮、编辑与参考说明弹窗。
- `dist/paper.js`：十个变体、纸窗几何、角色数据、表单和交互。
- `dist/paper.css`：纸张材质、分层动画、桌面与窄屏布局。
- `dist/assets/`：人物、装备、纸纤维和桌面素材。

当前入口只加载 `paper.js` 与 `paper.css`，由这两个文件维护共享卡面及十个变体。
