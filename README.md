# 纸上冒险 · 十种车卡实验

以 Curio 348「谁小时候没有这样的一次纸上冒险」为视觉方向，结合现有 TRPG 组件化模板的身份、属性、职业、技能、特征、背景结构。

## 预览

打开 dist/index.html，或使用静态文件服务器打开 dist/。发布版本：https://paper-adventure-ten-studies.shenzh2012.chatgpt.site

1. 冒险手册：手绘双页、打孔属性、彩色状态条。
2. 口袋档案：旅行证与单程票，便携档案。
3. 森林采集簿：草木标本、观察笔记和绿色页签。
4. 旅途地图：四个地图站点组成车卡过程。
5. 工会登记册：盖章登记、证件照片、横向能力表。
6. 秘术折页：墨紫三联页与星盘。
7. 剪贴手账：胶带、照片、信纸与散落记录。
8. 航海日志：海图与船员资料，靛蓝双页。
9. 夜行调查：夜色桌面、物证与调查档案。
10. 组件拼装台：六类组件自由选择与重排。

## 可操作内容

- 编辑身份、年龄、职业、背景与重要之人。
- 八属性点数汇总；480点预算提示；HP/MP上限、兴趣点、职业点联动。
- 编辑/搜索技能，D100 检定并显示困难和极难阈值。
- 增减生命/魔法/理智，勾选特征和行囊。
- 收藏设计方向，切换桌面/390px窄屏，组件选择/排序，导出JSON。
- 所有变体共享同一角色，编辑仅保存在当前浏览器本地。

这是交互与视觉原型，使用简化规则演示；没有连接正式角色库，也不包含完整规则书/职业技能点分配引擎。职业点演示：古物学者/民俗医生 EDU×4，私家侦探 EDU×2+DEX×2，旅行记者 EDU×2+APP×2。

## 素材与参考

视觉参考：https://curio.taugocauci.dev/item/348

原创角色与地图素材由内置 image_gen 生成，保留透明背景。提示词方向：细黑/棕钢笔不规则线条、克制淡水彩与彩铅质感、古典 RPG 冒险手账；墨绿斗篷、砖红围巾的旅行学者，以及森林、小镇、河流、群山构成的横向地图。无外部图片请求。

源文件为原生 HTML/CSS/JavaScript，不需要构建工具。dist/variants/ 按方案组划分；components.js 为共享表单组件，app.js 为共享状态与交互。
